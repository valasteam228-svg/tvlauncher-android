# TV Launcher для Android TV

Тот же интерфейс, что и в версии для Windows, но как домашний экран для Android TV / Google TV (Xiaomi Mi Box, Mi TV Stick и др.).
Система не заменяется и не прошивается, поэтому откат занимает минуту.

## 1. Собрать APK (на компьютере)

Вариант А, через GitHub (без установки чего-либо):
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки.
2. Вкладка Actions, затем Build APK, затем Run workflow.
3. Когда сборка закончится, скачайте файл `app-debug.apk` из раздела Artifacts (TVLauncher-apk).

Вариант Б, через Android Studio: откройте эту папку, подождите синхронизацию, затем Build, Build APK(s).

## 2. Поставить на приставку

1. На приставке: Настройки, Об устройстве, 7 раз нажмите на «Сборка» (включится режим разработчика).
2. Настройки, Для разработчиков, включите «Отладка по USB» (или «по сети»).
3. Установите APK одним из способов:
   - по сети с компьютера: `adb connect IP_ПРИСТАВКИ:5555`, затем `adb install -r app-debug.apk`
   - с флешки: поставьте на приставку любой файловый менеджер (например X-plore), разрешите установку из неизвестных источников и откройте APK с флешки.
4. Лаунчер появится в списке приложений приставки (значок TV Launcher).

## 3. Сделать его главным экраном

Сначала попробуйте (на компьютере, через adb):

    adb shell cmd package set-home-activity com.tvlauncher.app/.MainActivity

Нажмите «Домой» на пульте. Если открывается старый экран, отключите стандартный (это обратимо):

    adb shell pm disable-user --user 0 com.google.android.tvlauncher
    (для Google TV: com.google.android.apps.tv.launcherx)

Точное имя стандартного экрана зависит от модели: посмотреть можно командой
`adb shell pm list packages | findstr launcher` (Windows) или `| grep launcher` (Linux/macOS).

## 4. Откат

    adb shell pm enable com.google.android.tvlauncher
    adb uninstall com.tvlauncher.app

## Как это работает

- YouTube, Netflix, Twitch, Spotify, Кинопоиск и др. открываются установленными на приставке приложениями (список в `Bridge.java`, массив APPS). Если приложения нет, сайт откроется во встроенном окне браузера.
- Wi-Fi, Bluetooth, звук и дата открывают системные настройки Android. Громкость и «Без звука» работают из лаунчера.
- Кнопка «Назад» = Esc в интерфейсе, «Домой» всегда возвращает в лаунчер.

## Ограничения

- Встроенный браузер простой: страницы листаются стрелками пульта. Для YouTube лучше поставить YouTube для Android TV или SmartTube.
- Проект собран без возможности запустить его на реальной приставке, поэтому первую сборку проверьте и пришлите текст ошибки, если что-то не заработает.
